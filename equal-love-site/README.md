# ＝LOVE FAN REVIEW

＝LOVEのニュース、ディスコグラフィー、ライブ情報をまとめたFlask製ファンサイトです。CDカードからサイト内の作品詳細へ移動し、SQLiteデータベースへレビューを投稿できます。

## 起動方法

1. Python 3.10以上をインストールします。
2. Windowsでは `start_site.bat` をダブルクリックします。初回のみ仮想環境と必要なパッケージが自動で準備されます。
3. 手動で起動する場合は `python -m pip install -r requirements.txt` の後に `python app.py` を実行します。
4. ブラウザで `http://127.0.0.1:5000` を開きます。

## 主な機能

- 起動時の＝LOVEロゴアニメーション
- 公式公開情報を整理したメンバー10人の紹介ページ
- スクロール表示、ページ遷移、カードホバー、スマートフォンメニュー
- CD作品一覧と作品ごとのレビュー詳細ページ
- レビューの新規登録（INSERT）と一覧表示（SELECT）
- レビューの編集（UPDATE）と削除（DELETE）
- サーバー側とブラウザ側の入力チェック
- ライブグッズ画像の拡大表示

## ファイル構成

- `app.py`: Flaskの画面処理・データベース処理
- `schema.sql`: SQLiteのテーブル定義
- `templates/`: Jinja2テンプレート
- `static/css/style.css`: 全ページのデザイン
- `static/js/main.js`: アニメーションと画面操作
- `static/img/`: 画像素材
- `instance/love_reviews.db`: 初回起動時に自動作成されるSQLiteデータベース

## テンプレートコードの読み方

`templates`フォルダーのHTMLでは、Flaskから受け取ったデータを表示するためにJinja2を使用しています。

```html
{# メンバーの数だけ、以下のカードを繰り返す #}
{% for member in members %}
  <article>
    <h2>{{ member['name'] }}</h2>
  </article>
{% endfor %}
{# メンバーカードの繰り返しはここまで #}
```

- `{% for ... %}`: 繰り返し処理の開始
- `{% endfor %}`: 繰り返し処理の終了
- `{% if ... %}`: 条件に合うときだけ処理する範囲の開始
- `{% else %}`: 条件に合わなかった場合の処理へ切り替える
- `{% endif %}`: 条件分岐の終了
- `{{ ... }}`: Pythonやデータベースから受け取った値を画面へ表示する
- `{# ... #}`: ブラウザーには表示されない、テンプレート内の説明コメント

HTMLは2スペースずつ字下げし、親要素の中にある子要素ほど右側へ配置しています。同じ位置に戻った行が、そのまとまりの終了位置です。
